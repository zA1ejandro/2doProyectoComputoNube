⚙️ Arquitectura Docker

La infraestructura consta de dos servicios orquestados en docker-compose.yml:

  • web: Contenedor con Django, Python 3.12 y cliente MariaDB (expuesto en puerto 8080:8080).
  • db: Contenedor con la imagen oficial mariadb:latest con volumen persistente mariadb_data.
  • entrypoint.sh: Script que espera la disponibilidad de MariaDB y ejecuta automáticamente manage.py migrate.
